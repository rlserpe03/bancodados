DDL - Data Definition Language Passo 1 de 3

Criação da Tabela alunos

Define a estrutura lógica do banco de dados com chave primária, chaves únicas e tipos de dados adequados.

01_create_table_alunos.sql 
CREATE TABLE alunos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    ra VARCHAR(20) NOT NULL UNIQUE,
    nome VARCHAR(100) NOT NULL,
    cpf CHAR(11) NOT NULL UNIQUE,
    rg VARCHAR(20),
    cep CHAR(8) NOT NULL,
    endereco VARCHAR(150) NOT NULL,
    numero VARCHAR(10),
    complemento VARCHAR(50),
    bairro VARCHAR(50),
    cidade VARCHAR(50) NOT NULL,
    estado CHAR(2) NOT NULL,
    data_cadastro TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Explicação dos Tipos de Dados

  • AUTO_INCREMENT / PRIMARY KEY: Gera uma chave primária numérica única automaticamente.
  • CHAR(11) / CHAR(8): Usado quando o número de caracteres é fixo (como CPF sem pontuação ou CEP).
  • VARCHAR(X): Alocação dinâmica de espaço para textos de tamanho variável (nome, endereço).
  • UNIQUE: Garante que não existirão dois alunos com o mesmo RA ou CPF.

Dica do Professor

Note que guardamos apenas números limpos em campos como CPF (11 dígitos) e CEP (8 dígitos). Evitar traços e pontos no banco economiza espaço de armazenamento e facilita validações na aplicação backend.

Quando um aluno não possui complemento de endereço (por exemplo, casa em vez de apartamento), utilizamos o valor NULL sem aspas.

DQL - Data Query Language Passo 3 de 3

Consultas e Filtros (SELECT)

Exemplos práticos de seleção de dados para relatórios e buscas específicas.

1. Listar TODOS os dados cadastrados 
SELECT * FROM alunos;
📌 Uso: Retorna todas as colunas e todos os registros salvos na tabela.
2. Selecionar apenas colunas específicas 
SELECT ra, nome, cidade, estado 
FROM alunos;
📌 Uso: Otimiza a consulta trazendo apenas a listagem simplificada de localização.
3. Buscar aluno específico pelo RA 
SELECT * FROM alunos 
WHERE ra = '20260001';
📌 Uso: Filtra exatamente o registro correspondente à matrícula do aluno.
4. Filtrar alunos por Estado (UF) 
SELECT nome, cpf, cidade 
FROM alunos 
WHERE estado = 'SP';
📌 Uso: Retorna dados apenas dos alunos que moram no Estado de São Paulo.
5. Busca por aproximação de Nome (Operador LIKE) 
-- Alunos cujo nome começa com a letra 'M'
SELECT ra, nome, cidade FROM alunos WHERE nome LIKE 'M%';

-- Alunos que possuem 'Silva' em qualquer parte do nome
SELECT ra, nome FROM alunos WHERE nome LIKE '%Silva%';
📌 Uso: O caractere coringa % representa qualquer sequência de texto.
